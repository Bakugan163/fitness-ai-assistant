**Версия:** 1.1 (Актуализировано по ходу разработки)
**Статус:** В разработке (Итерация 1 завершена)
**Целевая платформа:** Web (REST API + фронтенд в будущем)

---

## 1. Общие сведения

### 1.1. Назначение системы
Веб-приложение, которое на основе антропометрических данных, целей, ограничений и предпочтений клиента формирует с помощью AI (LLM + RAG) персонализированную программу тренировок, план питания и рекомендации по режиму. Система поддерживает три роли — клиент, тренер, администратор — и ведёт трекинг прогресса подопечных.

### 1.2. Роли пользователей
*   **CLIENT (Клиент)** — заполняет профиль, выбирает тренера, генерирует программы, ведет трекинг прогресса.
*   **TRAINER (Тренер)** — видит своих подопечных, их профили, программы и прогресс; может вручную корректировать программы.
*   **ADMIN (Администратор)** — управляет пользователями, справочниками (упражнения, продукты) и просматривает логи.

## 2. Технологический стек (Актуальный)

*   **Язык:** Java 25 (LTS).
*   **Фреймворк:** Spring Boot 4.1.2.
*   **Сборка:** Maven (использование Maven Wrapper `mvnw`).
*   **База данных (Dev):** H2 (файловый режим `jdbc:h2:file:./data/fitnessdb` с `AUTO_SERVER=TRUE`).
*   **База данных (Prod/Target):** PostgreSQL + расширение `pgvector`.
*   **Миграции:** Flyway (отключен на этапе H2, будет включен для Postgres).
*   **Безопасность:** Spring Security, JWT (JSON Web Tokens), хеширование паролей BCrypt.
*   **Документация API:** Swagger UI / OpenAPI 3 (SpringDoc 3.x).
*   **AI/LLM:** GigaChat (Sber) — интеграция через Spring AI.
*   **ORM:** Spring Data JPA / Hibernate 7.

---

## 3. Архитектура проекта

Используется классическая слоистая архитектура:
*   `Controller` — принимает HTTP-запросы, валидирует DTO, возвращает JSON.
*   `Service` — содержит бизнес-логику (проверки, маппинг, вызовы AI).
*   `Repository` — работа с базой данных.
*   `Entity` — сущности БД.
*   `DTO` — объекты для передачи данных (Record-классы).
*   `Exception` / `GlobalExceptionHandler` — централизованная обработка ошибок (409 Conflict, 404 Not Found, 401 Unauthorized).
